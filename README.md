# VentureVerse 2026 — Event Landing Page

A beginner-friendly, responsive one-page event website made for the **EDC JSSUN Technical Team Task Round (First-Year Applicants)**.

## How to view
1. Download or extract the project folder.
2. Open `index.html` in any modern browser.
3. For editing, open the folder in VS Code and change `index.html`, `style.css`, or `script.js`.

No build tools, frameworks, or installation are required. An internet connection is only needed to load the optional Google Fonts; the page works with fallback fonts too.

## Included sections
- Header with section navigation and responsive mobile menu
- Hero section with event name, tagline, date, time, venue, and call-to-action
- About section with three event highlights
- Six-item schedule based on the provided mock event brief
- Two fictional guest profiles
- Footer with EDC branding and website link
- Demo registration form with client-side validation and confirmation message

## Design and accessibility
- Responsive layout for desktop and mobile screens
- Clear visual hierarchy, readable contrast, and visible focus state for the form input
- Semantic HTML landmarks, descriptive labels, and live status message
- Reduced-motion preference supported
